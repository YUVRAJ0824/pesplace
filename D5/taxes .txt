about fastapi

fastapi is a modern python web framework for building fast, high-performance rest apis. it automatically handles request/response validation, serialization, and generates interactive documentation.

key features:
- fast performance with automation
- built-in data validation 
- auto-generate interactive api documentation ,swagger ui

import/export tax rates by country
note: all tax rates are based on 2026 standards

countries: usa, india, china, germany, japan
products: car, bike, phone, laptop, smartwatch


quick tax summary:
usa: low tariffs (0-2.5%)
india: highest tariffs (10-100%, cars at 100%)
china: moderate tariffs (5-25%)
germany: moderate tariffs (0-10%)
japan: zero tariffs
example: car tax rates across all countries


country import tax (%) export tax (%)
usa        2.5       0.5
india      100        0
china      25         0
germany    10         0
japan      0          0


if you import a car to india
 you pay 100% import tax. in usa, you only pay 2.5%. japan has the lowest tax at 0%. most countries charge little to no export taxes on cars.
